# Host compatibility

Use this only when the host cannot provide direct user interaction with a discussion subagent or cannot delegate work.

For discussion isolation, use a separate discussion chat and start execution from its agreed brief. If the user chooses one chat, relay questions and answers and explain that the coordinator retains that exchange; a summary cannot remove messages already received. Follow the host's authorization rules for creating or messaging chats.

If subagents are unavailable, explain the limitation and let the user choose separate chats or sequential execution. Describe sequential work as such, rather than claiming independent review. Preserve the same user-acceptance and verification requirements whichever route is chosen.
