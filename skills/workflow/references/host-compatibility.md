# Host Compatibility

Use this guide only when the agent host cannot delegate work to subagents.

## Fallback Execution Modes

Explain the limitation to the user and let them choose one of two options:

- **Option A: Separate Chats**
  - Start a dedicated chat for each role (Implementation, Quality).
  - Seed each chat with the agreed brief and its relevant role reference document.
- **Option B: Sequential Execution in Current Chat**
  - Execute roles step-by-step within the same conversation.
  - Transparently describe sequential work as such, rather than claiming independent review.

Whichever route is chosen, preserve the exact same user-acceptance and verification requirements, and follow the host's authorization rules for creating or messaging chats.
